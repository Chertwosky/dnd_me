# QA checklist: правая шторка мастера

## Подготовка
1. Открыть комнату мастера в браузере и убедиться, что виден toggle шторки.
2. Проверить сценарии в desktop и mobile эмуляции.

## Чек-лист

### 1) Open/close и быстрые повторные клики
1. Нажать toggle для открытия шторки.
   - Ожидаемо: шторка открывается, backdrop появляется, `aria-expanded=true`.
2. Нажать toggle для закрытия.
   - Ожидаемо: шторка закрывается, backdrop исчезает, `aria-expanded=false`.
3. Быстро нажать toggle 5–10 раз подряд.
   - Ожидаемо: состояние остаётся консистентным (нет «залипания», финальное состояние соответствует последнему клику).

### 2) Закрытие по Escape и backdrop
1. Открыть шторку и нажать `Escape`.
   - Ожидаемо: шторка закрывается.
2. Открыть шторку и кликнуть по backdrop.
   - Ожидаемо: шторка закрывается.
3. Повторить эти действия несколько раз подряд.
   - Ожидаемо: обработчики работают стабильно, побочных эффектов нет.

### 3) Edge-case: очень узкий экран
1. Установить viewport около 300px ширины.
2. Открыть шторку и проверить slider ширины.
   - Ожидаемо: максимальная доступная ширина не уходит ниже минимального порога 360px.
3. Проверить подписи табов.
   - Ожидаемо: включается ultra-compact режим (иконки/короткие подписи), элементы не ломают layout.

### 4) Edge-case: максимальная ширина
1. Установить широкий desktop viewport (например, 1920px).
2. Передвинуть slider вправо до максимума.
   - Ожидаемо: шторка ограничена desktop max (980px), шире не становится.
3. Перейти на tablet viewport (~1000px).
   - Ожидаемо: max автоматически ограничивается до tablet max (760px), текущее значение clamp'ится при необходимости.
4. Перейти на mobile viewport (~500px).
   - Ожидаемо: max ограничивается до mobile max (560px) с адаптацией текущего значения.

## Признаки регрессии
- Шторка не закрывается по Escape или backdrop.
- После серии быстрых кликов toggle состояние расходится с UI.
- Значение ширины выходит за min/max пороги для текущего viewport.
- На узком экране кнопки табов обрезаются так, что нельзя переключить вкладку.
